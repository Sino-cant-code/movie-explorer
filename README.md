# MovieExplorer

A responsive movie browsing app built with React, Tailwind CSS, and DaisyUI. Users can browse shows, search by title, and view detailed information in a modal.

## Features

- Home page with hero banner and call-to-action
- Movie listing page with live search
- Responsive grid of movie cards (poster, title, rating, release year)
- Details modal with summary, genre, rating, and release date
- Data fetched from the [TVMaze API](https://www.tvmaze.com/api)

## Tech Stack

- React (Vite)
- React Router
- Tailwind CSS
- DaisyUI
